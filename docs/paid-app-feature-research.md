# Paid sleep-sound app feature research

Reviewed 22 November 2026 using publisher support docs, release notes and developer-authored store descriptions. Features are verified against those sources. Playback and screen-lock behavior require device testing.

Sleep Sounds already has seven mixable sounds, eight presets, device-local preferences and gapless looping. The native app bundles the sounds and the web app can save the library for offline use. Native playback notifications expose play/pause, and the web player registers media controls in supported browsers. The web Screen-off mode uses a longer rendered track that can briefly pause at the loop boundary. [Project README](../README.md), [native playback](../mobile/useSoundscape.ts), [web player](../dist/app.js).

## Priorities for Sleep Sounds

1. **Sleep timer with a gentle fade.** Start with a few countdown durations, visible time remaining and a cancel action. Fade the whole mix to silence and preserve its saved levels. Remember the last duration for quick reuse. Verify expiry and fade with the screen locked and offline in native playback and both web modes before promising support there.
2. **Named local mixes.** Save the current seven levels under a user-chosen name, then allow one-tap recall, rename and delete. Keep these mixes in device-local storage alongside the built-in presets so users can return to several blends.
3. **Quick access to a saved mix.** Once saved mixes exist, consider a native shortcut to a chosen mix. Dark Noise shows what this adds beyond the existing play/pause controls. Rain Rain’s per-layer tone shaping is a lower-priority option if users ask for softer versions of existing sounds.
